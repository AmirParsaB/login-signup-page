# Login & Sign Up Page

A modern login and sign-up interface built with HTML, CSS, and JavaScript, featuring a clean design, smooth transitions, and a responsive layout.

## Overview

This project is a front-end implementation of a login and registration interface, created to practice web development and showcase front-end development skills.

## Features

- Login and sign-up forms
- Animated transitions between forms
- Social media icons
- Custom Montserrat typography
- Interactive buttons and hover effects
- Responsive layout
- Accessibility considerations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Boxicons
- Montserrat

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (optional)

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/AmirParsaB/login-signup-page.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser, or use the Live Server extension.
